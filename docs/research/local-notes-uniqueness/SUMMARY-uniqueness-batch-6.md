## Word counts vs target — batch-wide overage, stated plainly

Target for Tier 2 is 400–600 words of new facts. **All 25 notes exceed it** (1,167–2,526 words excl. URLs). No note is short; none was padded. Every worker hit the same wall independently: the mandated structure cannot fit in 600 words — §4 alone requires 4–6 Q&A pairs at 40–90 words per answer (160–540 words), on top of 5–8 §5 bullets, a required §6 with status + read-date per project, §§7/9 with named bylaws and figures, and a §10 comparison table. Delivered notes from earlier batches, measured the same way, run the same range (e.g. scott-creek-coquitlam ≈2,100; ladner-houses ≈899), so this batch matches program practice rather than gutting mandated sections. If a hard 600-word ceiling is wanted, it requires a separate cut pass (safest trim points: §5 and §8 bullets) and a ruling that overrides the section minimums in the brief.

Longest files and why: brookswood-mobile-homes (2,526) carries all Township-wide mobile-home facts in full by allocation; surrey-mobile-homes (2,400) carries the full Surrey park roster; cost-of-mobile-home-pad-rental-fees-in-langley (2,007) is the program's designated full provincial pad-rent rules page (formula, assignment, closure compensation, forms, deadlines).
