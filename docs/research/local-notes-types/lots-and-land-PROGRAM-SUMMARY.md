# Local Notes — LOTS AND LAND program summary (all batches, November 1–2, 2026)

**Program:** one local-notes file per researched area and sub-area for the region's lots and land — Fraser Valley, Metro Vancouver, the North Shore and the Sea-to-Sky/eastern-valley edge — built from the area-research program's 503 research files (`~/workspace/area-research-2026-11/`, batches 1–18 + missing/). Where the 55-plus, condos and townhomes programs counted buildings and complexes, this program documents **the land itself**: what land actually trades in each area, in what legal form, and under what rules.

**Files:** 503 lots-and-land files in `~/workspace/local-notes/lots-and-land/` (this summary is the 504th file in the folder), delivered in 21 batch zips (`lots-and-land-batch-1.zip` … `lots-and-land-batch-21.zip`). ## Format adaptations for land (settled in L1 and held program-wide)

- **§2 is THE LAND ITSELF, not a building roster.** Named subdivisions and bare-land developments are documented by name only where an official/developer source verifies them. **Bare-land STRATA is documented as its own form** (strata tenure on the lot — Form B, fees and bylaws apply to the lot itself); fee-simple lots are the default form; historic subdivisions are documented as built lot fabric; assemblies, development sites and rezoning proposals are documented **AS SUCH, never as inventory**; presale LOT offerings are counted separately, never mixed with resale stock.
- **Honest negatives at the top.** Where an area has no meaningful bare-land market, §2 says so plainly at the top instead of padding a roster. Most files in this program are honest negatives of exactly that kind (below).
- **Topic, price-band and city-wide files carry NO roster** — §2 says so plainly; city files cross-reference the sub-area land files and take no counts; band status is UNCONFIRMED per parcel; worked PTT examples state their inputs and show the tier math (anchor set in every file: $500K → $8,000; $700K → $12,000; $800K cap → $14,000, $6,000 for a fully qualifying first-time buyer; $900K → $16,000; $1.0M → $18,000; $1.2M → $22,000; $1.5M → $28,000; $1.8M → $34,000; $2.0M → $38,000; $3.5M → $93,000 including the further 2% tier — see open item 1).
- **Document-once discipline.** A named land development is documented once, in its home area's file; variants and neighbouring files cross-reference. Where the same ground exists under two slugs, the first lots file written is the land home and the later file carries a status block (tsawwassen-north/guide, central-abbotsford/guide, seaisland/sea-island, east-newton-guide, west-newton-guide, matsqui-guide, abbotsford-east-guide, english-bluff-guide, holly-guide, port-guichon-guide, neilsen-grove-guide, steelhead, walnut-grove-guide and whitby-estates precedents).
- **Rules held to primary sources.** GST on vacant land is stated **only at the CRA GI-003 level** in every file (developer/business sales and newly subdivided lots generally taxable; an individual's personal-use land generally exempt) — a condos sibling's finer GST framing was not carried anywhere. The FTHB GST rebate is stated as applying to new HOUSING, not bare land. Servicing-bylaw numbers are carried only where verified from the city's own text (ledger below); where unconfirmed, the file documents the process instead. The federal non-Canadian purchase prohibition is left at each file's own cited sources, unconformed across files (open item 4).
- **SnapStats has no land category.** Covered-community files cite SnapStats only as labelled community context (Detached vs "Condos & Townhomes" combined, September 2026); a detached figure is never presented as a land figure, and no SnapStats figure of any kind is carried for Vancouver, Richmond, North/West Vancouver, Squamish, South Delta, Chilliwack, Anmore or FVRD/CADREB ground, which SnapStats does not cover.

- Verified-negative files state the negative plainly at the top of §2 rather than padding a roster — the 16-entry roster above is short because the region's verified bare-land strata stock is short, and the files say so.
