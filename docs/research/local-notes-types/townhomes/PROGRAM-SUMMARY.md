# Local Notes — TOWNHOMES program summary (all batches, November 1–2, 2026)

**Program:** one local-notes file per researched area and sub-area for the region's townhouse stock — Fraser Valley, Metro Vancouver, the North Shore and the Sea-to-Sky/eastern-valley edge — built from the area-research program's 503 research files (`~/workspace/area-research-2026-11/`, batches 1–18 + missing/).

**Files:** 503 townhomes files in `~/workspace/local-notes/townhomes/` (this summary is the 504th file in the folder), delivered in 20 batch zips (`townhomes-batch-1.zip` … `townhomes-batch-20.zip`). Every file has the same five sections: (1) streets and boundaries, (2) complexes, (3) rules that affect townhomes, (4) what buyers ask, (5) local details a buyer would not know — with a source URL after every fact and UNCONFIRMED wherever no source settles a point. The core diligence item in every §2 is tenure: STRATA vs FEE-SIMPLE stated explicitly for every counted complex.

**Coverage (disk-verified Nov 2, 2026):** all 503 researched areas have a townhomes file. Batches 1–18 were completed in T1–T18, the missing-area set in T19–T20.

**Headline count: 366 verified unique townhouse complexes region-wide**, each counted once, in its home file. Every counted complex was verified by name AND tenure (current listings, MLS data sheets, developer or title evidence). Assembly, guide-variant, topic and price-band files count 0 new unless the variant rule passes (own research names the complex + fresh verification establishes it + no sibling counts it); assembly cross-reference totals are never added again. Presales are counted separately in their files and are never inside the 366. This is a sum of verified entries, not a census: absence of a count in a file means no complex passed verification there, not that no townhouse exists.
