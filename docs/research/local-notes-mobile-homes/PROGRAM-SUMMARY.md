# Local Notes — MOBILE HOMES program summary (all batches, November 1–2, 2026)

**Program:** one local-notes file per researched area and sub-area for the region's mobile / manufactured homes — Fraser Valley, Metro Vancouver, the North Shore and the Sea-to-Sky/eastern-valley edge — built from the area-research program's 503 research files (`~/workspace/area-research-2026-11/`, batches 1–18 + missing/). Where the lots-and-land program documented the land itself, this program documents **the manufactured-home position of every area**: whether a manufactured-home park, a bare-land strata manufactured-home community, a co-op or an own-land manufactured home actually exists there, in what tenure form, and under what rules — and, just as often, states plainly that no manufactured-home stock exists in the area at all.

**Files:** 503 mobile-homes files in `~/workspace/local-notes/mobile-homes/` (this summary is the 504th file in the folder), delivered in 21 batch zips (`mobile-homes-batch-1.zip` … `mobile-homes-batch-21.zip`). Every file has the same five sections: (1) streets and boundaries, (2) **the parks and the homes**, (3) rules that affect mobile homes (the full settled MHPTA block), (4) what buyers ask, (5) local details a buyer would not know — with a source URL after every fact and UNCONFIRMED wherever no source settles a point. **This summary IS inside `mobile-homes-batch-21.zip`** (which contains exactly this batch's 4 new files: the final 3 notes + this summary), as the M21 delivery instruction specifies.

## Method note

Each mobile-homes file was built on its area's research file plus **all** sibling program files for the same ground (55-plus, condos, townhomes, lots-and-land, acreages — read from disk, not from briefs), with official/primary sources first. The program's working discipline is **SOURCE/DISK governs**: where a brief line, a sibling's framing or a research file's shorthand conflicted with a primary source or with the disk, the source/disk governed and the file says so — the named precedents include riverwood (Port Coquitlam, not Surrey), the New Westminster RT-A/RT-B corrections (brunette, connaught-heights, sapperton and uptown-nw research files all carried districts that do not exist), Queensborough (floodplain Zone 1), the Lee Building (tenure held OPEN over a sibling's finer label), Montecito (its own SD41 locator run over the Sperling shorthand), and Cultus Lake Village (documented by tenure form, never upgraded to operator-verified). Standing corrections banked by the earlier programs were carried into every mobile file without re-asking: Surrey 2050 OCP 21900 replacing 18020; Burnaby Zoning Bylaw 2026 No. 14815, never 4742; Mission OCP 6405-2026 adopted April 21, 2026; the Maple Ridge Lougheed Corridor adopted position ending at 221 St; the corrected floodplain ledger; Pitt Meadows' 95% floodplain figure; and the Neilsen Grove spelling lock.

## What the program did not do

- No sold prices, and no listing addresses or asking prices beyond the named parks/communities themselves, in any file.
- No SnapStats mobile-home figures — mobile homes have no SnapStats category; covered-community files carry community context only, labelled, and uncovered communities carry none.
- No pad-rent dollar figure published as fact anywhere; MHPTA limits are stated as the 2026 = 2.3% + proportional / 2027 = 2.2% + proportional caps only, and a manufactured home on a rented pad is stated throughout as NOT land ownership.

- No count was taken, moved or revised in any sibling program: this program's files cross-reference the condos, townhomes and lots-and-land rosters in their home files and change none of them. Count moves, where a future pass wants one, require annotations in both files.
- Verified-negative files state the negative plainly at the top of §2 rather than padding a roster — the headline yield above is no new verified park in M4–M21 because the region's verified manufactured-home park stock was already fully documented, by tenure form, at its home grounds.
