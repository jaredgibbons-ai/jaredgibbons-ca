# Competitor Gap Analysis — Abbotsford, Chilliwack + Langley

Prepared for Jared Gibbons (Royal LePage Little Oak Realty) — 2026-11-01.
Method: top agents/teams per area identified via web search; their area pages opened and audited 2026-11-01 for what they provide (listings feed, sold data, stats, schools/catchments, amenities, guide depth, video, lead magnets, alerts, home evaluation, blog). Google ratings are included only where publicly visible in search results and are labelled as observed via web search 2026-11-01 — they are not ranking claims. Competitor figures are described, never restated as facts. "What's Missing" = what NONE of the top agents in that area provides — the openings for Jared's pages.

# Competitor Gap Analysis — Cluster 1: Abbotsford (Sumas Mountain, Aberdeen, Abbotsford East, Abbotsford West)

Research date: 2026-11-01. Method: web search for neighbourhood-level agent presence, then opening the actual agent/team pages listed below. Portal sites (REALTOR.ca, Zolo, REW, Wahi, Strawhomes) were excluded from "top agents" — only agent/team/brokerage-owned sites are profiled. Where a page could not be opened because the page-fetch service returned an error, that is stated on the entry and the checklist is based on the full page text returned in search results on 2026-11-01, marked accordingly. Ratings are only shown where a rating + review count was publicly visible in search results, and are labelled "observed via web search 2026-11-01" — they are not ranking truth. Agents below "appear prominently in search" for the area; no ranking position is claimed.

A note that applies to all four areas: almost no Abbotsford agent has a true neighbourhood page. The dedicated neighbourhood pages that exist are mostly templated pages from out-of-area teams (a Vancouver Island team and a Surrey team, below) that publish the same template for hundreds of BC neighbourhoods. Local Abbotsford agents mostly have one city-wide listings page and no neighbourhood content at all. That pattern is itself the main finding.

### 3. WHAT'S MISSING — what NONE of them provides for Sumas Mountain

- **No local-agent neighbourhood page at all.** No Abbotsford-based agent/team publishes a Sumas Mountain page; the only dedicated page is a templated page from a Vancouver Island team.

- **No sub-community breakdown with real depth.** Straiton, Auguston and Barrowtown are named in one paragraph (Loyal Homes) but get no individual treatment, maps, or boundaries.
- **No video, no downloadable guide, no neighbourhood-specific email alert** on any of the three.
